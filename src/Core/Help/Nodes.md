# Processor parameter reference

Child pages are generated from the exact assembled native descriptors. Unary pages show only relevant parameters. Codec pages show shared parameters once and both directional groups. Each page includes ports, defaults, enums, variant conditions and bounds.

[Framing](help:processing.framing) · [Codecs](help:processing.codecs) · [Timestamp](help:processing.timestamp)

String defaults are shown as JSON literals. Quotes and escaped characters describe the stored value; they are not necessarily text to paste verbatim into a control.
