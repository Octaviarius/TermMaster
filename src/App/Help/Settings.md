# Settings and inheritance

Choose the appropriate scope: application, workspace, session or terminal. Search filters pages and fields without discarding drafts. Apply validates and commits through the settings owner; Cancel discards unapplied edits. Unknown configuration fields are retained. Reset removes a local override and reveals the inherited value.

Interface provides ordered lists for embedded and secondary toolbars/status controls. Choose an action or group, Add it and use up/down to reorder. An empty list hides all configured buttons. Unavailable plugin selectors remain stored.

F1 while a field is focused opens its current schema reference: defaults, allowed values, variant conditions and bounds.
