# Termaster help

Termaster opens a **workspace** containing named **sessions**. A session stores terminals, settings and layout. Restored terminals reconnect if they were connected when saved. New terminals start disconnected.

Use Contents to navigate and Search to search installed documentation. The page Find field searches the current page. Back and Forward retain navigation. Press F1 on a settings page or selected Lineflow operation for context. Help never starts devices or processors. Installed plugin help works while its plugin is disabled.
