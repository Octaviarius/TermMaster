# Keyboard shortcuts

| Operation | Default |
| --- | --- |
| Connect / disconnect / reconnect | Ctrl+Shift+S / X / R |
| Start / stop all | Ctrl+Alt+Shift+S / X |
| Buffered input | Ctrl+Shift+B |
| Local echo | Ctrl+Shift+E |
| Copy / paste / cut | Alt+C / V / X |
| Select all / undo / redo | Ctrl+Shift+A / Z / Y |
| New / open / close workspace | Ctrl+Shift+N / O / W |
| Save workspace | Ctrl+Shift+F2 |
| Help | F1 |

Configure bindings in Application → Keyboard shortcuts. Apply commits changes; Clear disables a binding; Reset restores its default. Explicit saved assignments take priority over implicit defaults. Conflicting explicit assignments must be resolved before Apply.

Plain Ctrl combinations retain terminal control-byte behavior. Native text editors retain their standard editing keys.
