Pinned revision: `53fab88ff9d1b48f4704b5b5b560d6b4d560bf4c`.

LICENSE. Downloads used the physical Ethernet adapter. No configure-time downloads.

The settings navigation subset also includes `app-window`, `keyboard`,
`panels-top-left`, `text-cursor` and `terminal` at the same pinned revision.
These files were fetched unchanged with curl bound to the physical Intel I211
Ethernet IPv4 address; destination routes used interface 14.

The Lineflow editor subset adds `plus`, `trash`, `arrow-right`, `chevron-up`,
`chevron-down`, `workflow`, `blocks`, `link` and `triangle-exclamation-point` from
this pinned revision. Downloads were bound to the physical Ethernet IPv4 address;
the resolved upstream route used interface 14. Upstream SVG files are unmodified.
